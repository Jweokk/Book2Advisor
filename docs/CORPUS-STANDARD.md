# 语料准入标准 v1.0（Method Advisor 数据质量门槛）

> 用途：决定哪些目标人物（及后续人物）资料可以进入 Method Model。所有语料在入库前按此标准过滤。
> 原则：**只进人物本人的方法论声音，排除一切二手解读与噪声。**

## A. 来源要求（硬性门槛，不满足即排除）

| # | 要求 | 说明 |
|---|---|---|
| A1 | 一手或可信二手 | 本人演讲/访谈**实录**（视频转录或文字稿）；央视/新华社/财经正规媒体专访**原文**；福耀官方发布 |
| A2 | 可追溯 | 能给出出处（媒体/节目名 + 日期 + 链接），无法追溯的不收 |
| A3 | 本人原话占比高 | 内容以他的直接引语为主（≥50%），非他人转述 |

## B. 内容要求

| # | 要求 | 说明 |
|---|---|---|
| B1 | 方法论密度 | 含经营判断、决策逻辑、原则表达、案例叙述（谈人生感悟但无方法含量的段落可截取/忽略） |
| B2 | 时间可标注 | 能确定大致时期（年份或阶段），供思想演变（evolution）使用 |

## C. 排除标准（一票否决）

- C1 二手解读/评论文章（别人分析、评价目标人物的）
- C2 自媒体标题党、营销软文、内容农场
- C3 AI 生成或疑似 AI 生成的文本
- C4 纯娱乐八卦、与经营方法无关
- C5 同一事件的低质量重复转述（同一演讲多个版本，只取最优/最完整版）

## D. 优先级（同质量下按此排序）

1. 央视/国家级媒体专访（《对话》《开讲啦》《遇见大咖》等）
2. 财经媒体长访谈（财经杂志、第一财经、亚布力论坛实录等）
3. 论坛/高校演讲实录（北大、清华、企业家论坛）
4. 其他可追溯访谈

## E. 数量与覆盖

- 每轮融合 2-3 份起步，总量建议 5-10 份后饱和（再增边际收益递减）
- 优先覆盖不同时期（创业期/发展期/国际化期/近年），利于 evolution 与跨期印证
- 与目标人物代表作主题重叠度高的访谈优先（可形成双源印证，升级 E 级）

## F. 流程

1. 搜索候选 → 2. 按 A-C 过滤 → 3. 生成候选清单（链接+评估）给用户过目 → 4. 抓取全文 → 5. convert.py 转换入库 → 6. 提取融合
