# 示例评估集 — 混淆题（confusions）10 题

> 设计原则：问题同时可联想到两条以上原则，但只有一条是正确主触发（答案唯一）。
> 期望：选中正确原则；选错（选中陪跑原则）即扣分。
> 陪跑原则在每题标题后注明。

1. 大客户要求我降价 30%，说不然就换供应商，可我的成本摆在那里，怎么办？
   （陪跑：据理力争 / 知雄守雌 → 正确：双赢不欺）
2. 公司有一块业务很赚钱但技术不先进，另一块技术领先但不赚钱，该主推哪块？
   （陪跑：长期主义 → 正确：聚焦专注）
3. 员工提出要成立工会集体争取权益，我该怎么回应？
   （陪跑：流程化质量改良 → 正确：以人为本）
4. 有人劝我做房地产赚钱快，说制造业太苦太慢，要不要转型？
   （陪跑：观天象知危 → 正确：聚焦专注）
5. 政府给了一块地建产业园，但要求我们同时配套做地产开发，接不接？
   （陪跑：合规经营 → 正确：聚焦专注）
6. 竞争对手盗用我们的技术专利，证据确凿，要不要告到底？
   （陪跑：知雄守雌 → 正确：据理力争）
7. 市场不好，有官员暗示我“识相点”别参加某次竞标，给别人留机会，怎么办？
   （陪跑：知雄守雌 / 合规经营 → 正确：据理力争）
8. 有富商捐钱给寺庙求平安，说这样能积德，您怎么看这种“慈善”？
   （陪跑：诚信守约 → 正确：慈善悲悯）
9. 我想给大学捐一栋楼换一个名誉校董的头衔，您觉得值吗？
   （陪跑：慈善悲悯 → 正确：教育公益）
10. 供应商坚持要涨价说他们也不容易，但别的供应商都愿意原价供货，怎么办？
    （陪跑：据理力争 → 正确：双赢不欺）
